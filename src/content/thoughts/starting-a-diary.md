Starting a diary again. Every so often I decide I want to write things down, but I can never keep up with a physical notebook. I really hope it sticks this time. I promised myself that this would not be for anyone but me. I don't want rules or deadlines; I will update these pages when I feel like it, when I remember, or when I have more time. It does not need to be perfect, however, I do have a few hopes.

I hope to see improvements in the overall look of the site. Through this "blog", I hope to improve my technical software skills, writing skills, and most importantly, my motivation towards self-growth. I hope to practice consistency in my hobbies and self-expression, while refining my time management.

I look forward to talking about my favourite things. I often enjoy having discussions about art, philosophy, politics/world news, and every day things. I have opinions that I like to share but not everyone shares the same interests as me...so what better thing to do than to write for myself.

So this time the rule is that **posting has to be boring.** A new entry is a text file
in a folder. No login, no dashboard, no editor that takes four seconds to load.

## What goes here

- Whatever I was thinking about
- Films, with a number attached so I can argue with myself later
- Shows, season by season, because I always forget where I left off
- Records I couldn't stop playing
- Photos, unedited, mostly of nothing
- And, maybe more to come

If it turns out I only ever use the movies section, that's fine too.
